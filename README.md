# SFG Learning Hub

SFG 구성원을 위한 사내 교육 포털입니다.

## 파일
- index.html : 메인 페이지
- styles.css : 반응형 디자인
- app.js : 교육 데이터, 필터, 상세 모달, 대상별 교육 경로
- netlify.toml : Netlify 배포 설정

## 배포 방법
1. 폴더 전체를 Netlify Drop에 드래그하거나
2. GitHub 저장소에 올린 뒤 Netlify와 연결하면 됩니다.

## 실제 운영 전 연결할 항목
1. SFG 공식 로고 이미지 적용
2. 실제 월별 교육 일정 반영
3. 교육 신청 버튼 → Google Form / Microsoft Form 연결
4. 법정의무교육 버튼 → 휴넷 LMS 연결
5. 교육 운영관리 버튼 → 기존 SFG Academy 관리자 페이지 연결
6. 자료실 → Google Drive / SharePoint 등 실제 파일 링크 연결

## 권장 운영 구조
- 직원용 포털: SFG Learning Hub
- HRD 관리자용: 기존 SFG Academy 교육 운영 관리
- 교육 신청: Google Form 또는 Microsoft Form
- 교육 자료: Google Drive / SharePoint
- 법정의무교육: 휴넷 LMS
