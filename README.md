# SFG Learning Hub

SFG 구성원을 위한 교육·직무·브랜드·현장지식 포털입니다.

## 주요 구조
- Skills: Service / Operation / Leadership / People / Expertise / VOC
- Learning Path: 점장 / 스탭 / 조리장 / 주차 / 안내데스크
- Brand Academy: 한식 / 일식 / 중식 / 바다를 먹은 고등어
- Field Manual: POS, 영업관리, 원가, 위생, 청결, 시설, 주차, VOC, 상권, 판촉 등
- Forms: 현장 업무 양식 목록
- 교육 일정

## Netlify 업데이트
이 폴더의 내용을 GitHub `sfg-learning-hub` 저장소에 덮어쓰기 업로드 후 Commit 하면
Netlify가 자동으로 기존 주소에 재배포합니다.

## 파일 구성
- index.html
- styles.css
- app.js
- netlify.toml
- manuals/ : 업로드된 SFG 원본 교육·매뉴얼 자료

## 향후 운영
교육자료가 추가되면 `app.js`의 manuals / paths / academies 데이터에 연결하면 됩니다.
